# ONNX Runtime Library / ONNX Runtime 运行库

`macos-arm64/libonnxruntime.dylib` is included to reproduce the validated Apple Silicon Go demonstration. It is distributed under the license in `ONNXRUNTIME_LICENSE.txt`.  
`macos-arm64/libonnxruntime.dylib` 用于复现已验证的 Apple Silicon Go 演示，其许可证位于 `ONNXRUNTIME_LICENSE.txt`。

For another platform, install the matching ONNX Runtime shared library and set `ONNXRUNTIME_SHARED_LIBRARY` to its absolute path.  
其他平台需要安装对应的 ONNX Runtime 动态库，并将 `ONNXRUNTIME_SHARED_LIBRARY` 设置为其绝对路径。
